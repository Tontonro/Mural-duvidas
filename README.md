## Objetivo

Adaptar o mural da aula para consumir a API DummyJSON, interpretar `dados.posts`, apresentar 67 publicações e permitir pesquisa por título, conteúdo e tags.

## Como executar

Abra o arquivo `index.html` na raiz do projeto diretamente no navegador ou use uma extensão de servidor local do VS Code. Clique em **Carregar publicações** para consultar a API. A aplicação precisa de conexão com a internet para acessar a DummyJSON.

## Funcionalidades

* Carrega 67 publicações da API DummyJSON.
* Permite pesquisar por título, conteúdo e tags.
* Ordena os cartões por ordem original, quantidade de curtidas ou visualizações.
* Exibe o total de curtidas das publicações visíveis após a pesquisa.

## API utilizada

https://dummyjson.com/posts

## Personalização implementada

Foi incluído um seletor para ordenar os cartões por quantidade de curtidas ou de visualizações. Também é apresentado o total de curtidas dos cartões que estão visíveis após a pesquisa.
